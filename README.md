# Trabajo Práctico Integrador - Unidad II - Sitio Web del IPF

**Materia:** Tecnicatura Superior en Desarrollo de Software Multiplataforma  
**Año:** 2026  
**Alumno:** Cabezas Mateo Luciano

## Descripción del Proyecto
Sitio web responsivo sobre el IPF con el fin de informar acerca de la institución, su historia, como se organiza, las carreras que ofrece y brindar información de contacto.

## Tecnologías Utilizadas
Para el desarrollo de esta web se emplearon las siguientes herramientas:

*   **HTML5:** Estructura semántica del contenido.
*   **CSS3:** Estilos personalizados y espaciado.
*   **Bootstrap 5:** Framework para el diseño responsivo (Grid System, Navs, Cards, Carrousel, List-Group, Table).
*   **Git & GitHub:** Control de versiones y despliegue del repositorio.
